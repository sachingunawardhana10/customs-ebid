# Customs eBid

## Secure Enterprise E-Auction Platform for Customs

Customs eBid is a secure enterprise-style electronic auction platform developed as a university final-semester project.

## Project Architecture

The system uses a Spring Boot microservices architecture with:

- Java 21
- Spring Boot
- Spring Security
- JWT
- PostgreSQL
- Redis
- Apache Kafka
- Eureka Server
- API Gateway
- Nginx
- Docker
- Docker Compose
- AWS

## Microservices

- User/Auth Service
- Auction/Item Service
- Bidding Service
- Payment Service
- Notification/Audit Service
